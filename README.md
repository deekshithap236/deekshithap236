- **Data Engineering**: Building high-performance data pipelines with **AWS (S3, Lambda, EMR, Glue, Athena, Redshift, Step Functions), Snowflake, and Apache Spark**.

- **Cloud & DevOps**: Optimizing cloud infrastructure, CI/CD pipelines, and monitoring solutions (**Docker, Terraform, CloudWatch**).
- **Business Intelligence & Data Analysis**: Designing impactful dashboards and reports using **Tableau, Power BI, Alteryx, Looker**, and **Adobe Analytics**. Experienced in **cloud-scale analytics** with **BigQuery** and skilled in **data storytelling** using **Vue.js, Plotly, D3.js**, and Python libraries like **Seaborn, Matplotlib, Pandas**.
